This is my personal 3D game engine, titled Dehumanizing Obelisk or DeO3D for short. The name is supposed to mean that DeO3D is like this monument that if you stand
before it for too long, it begins to transform you into a machine. It is very work in progress. My plan for the icon is to have a tall concrete monolith with the
text DeO engraved on the slanted front facing surface concrete, as if it is a name similar to Dio. Red light strips run down the same slanted surface, parallel
to each other and sandwiching the engraving. Near the bottom of the monolith, large fiber optic cables and power cables run from holes near the bottom,
stretching out indefinitely into the distance.

I also have thought about an actual game idea. Imagine Teardown but with breaching and milsim style gameplay. Indestructible objects are rendered with meshes to 
keep detail while not using expensive voxels, and destructible objects like drywall and wood doors use voxels for procedural destruction. Enemies will also be
made of voxels for them to be procedurally destroyed as well.
